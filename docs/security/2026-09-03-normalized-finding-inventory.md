## Required infrastructure verification

1. Configure the public listener/virtual host to accept only the documented PML hostnames and return a fixed 400/421 for unknown `Host`/`X-Forwarded-Host` values before forwarding.
2. Confirm ALB/Envoy strips inbound forwarding headers and rewrites them from trusted connection metadata; configure the Nest `TRUST_PROXY_HOPS` value only after the exact hop count is documented.
3. Replace or customize ALB/Envoy-generated 4xx/5xx responses so HSTS and the intended security-header baseline are present, and suppress avoidable `Server`/Envoy timing disclosure where the platform permits.
4. Disable TRACE and TRACK at the first controllable edge. Preserve OPTIONS for CORS preflight.
5. Investigate the matching 502 burst that caused all 12 missing-CSP/HSTS/server-version instances; verify target health, timeouts, image-optimizer resource limits and deployment availability.
6. No code or configuration should forward an arbitrary request host into an outbound destination. Validate this with an external canary domain, never the metadata service.
